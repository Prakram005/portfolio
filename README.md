## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Three.js
- Framer Motion
- MERN stack focus: MongoDB, Express.js, React, Node.js

## Local Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```

## Production Checks

```bash
npm run lint
npm run build
```
